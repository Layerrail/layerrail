## Crowdfunding and sponsorship

### Usable now

1. **GitHub Sponsors personal profile** — already approved and public. This is the only immediately live crowdfunding route with verified Nigeria support. The profile now presents LayerRail's open work, and the repository points to it through `.github/FUNDING.yml`.
2. **Open Collective with Open Source Collective fiscal hosting** — suitable in principle: worldwide open-source projects, organizational repository, recognized open-source license, active development, and preferably multiple administrators. OSC charges a 10% host fee. Account creation is blocked by Cloudflare Turnstile in the integrated browser, and GitHub's fiscal-host option requires an existing approved OSC profile URL first.

### Do not launch yet

- **GitHub Sponsors organization profile:** GitHub says a sponsored organization must legally operate in a supported region. LayerRail is explicitly pre-incorporation, so using the organization route would contradict the legal-status record. Continue with the approved maintainer profile until the company or fiscal host exists.
- **Kickstarter / Indiegogo / GoFundMe:** Nigeria is not a supported Kickstarter creator country, and these platforms are weak fits for recurring cloud software. A foreign shell should not be created solely to evade platform geography.
- **Equity crowdfunding / public SAFE:** wait until an issuer exists. U.S. Regulation Crowdfunding requires an eligible issuer, an SEC-registered intermediary, Form C disclosures, and ongoing reporting; the current maximum is $5 million per 12 months. Republic, Wefunder, StartEngine, Crowdcube/Republic Europe, and similar routes are post-incorporation projects, not pre-incorporation account signups.
- **Token/crypto crowdfunding:** excluded absent specialist securities advice and a genuine product need.

## Legal sequencing for public investment

1. Close founder-first grants, prizes, sponsorship, and conventional private SAFE interest while remaining explicit about pre-incorporation status.
2. Select an investor-compatible parent jurisdiction with startup and cross-border tax counsel.
3. Execute founder stock, vesting, IP assignment, option pool, banking, and compliance.
4. Reassess whether a regulated community round adds distribution value. Do not use Reg CF merely because conventional fundraising is difficult: it adds public disclosures, campaign costs, investor communications, and annual reporting.
